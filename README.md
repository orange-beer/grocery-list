# 每周买菜清单（grocery-list）

一个给家里人用的买菜清单网页。打开 `index.html` 就能用，**不需要安装任何东西、没有构建步骤**，直接双击或者丢到任意静态服务器上即可。

---

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | **主程序**。整个应用就这一个文件（HTML + CSS + JS 全在里面），130 种食材的数据、拼音、营养介绍也都写在这里面 |
| `download.js` | **图片下载脚本**。从 `蔬菜.md` 读取图片链接，下载到 `img/`，并可选地回写 `index.html` 里的 `img` 字段 |
| `蔬菜.md` | **食材数据源**。食材名、分类、季节标签、图标、图片链接的完整清单，加新菜时改这里 |
| `img/` | **本地图片目录**。文件名 = 食材名 + 扩展名，例如 `菠菜.jpg`、`苋菜.webp` |
| `README.md` | 本文件 |

---

## 怎么用

直接用浏览器打开 `index.html` 即可。应用有两种模式：

**挑菜模式**（默认）
- 顶部分类标签切换（叶菜 / 根茎 / 瓜果 / 菌菇 / 豆制品 / 调味 / 肉类 / 水产 / 蛋禽 / 其他）
- 点卡片选中，选中后可调数量、写备注；数量是 1 时再按 `−` 会取消勾选（备注保留，方便重新选中）
- 菜名旁边带拼音，左上角 `ⓘ` 看营养介绍
- 顶部搜索框支持模糊搜索：菜名、拼音（`bocai`、`bo cai`）、拼音首字母（`bc`）都能搜
- 「全选 / 清空 / ＋自选 / 分享」

**采购模式**（家人打开分享链接时自动进入）
- 精简的待办清单，点一下勾选已买到
- 右侧 `−` 可以把某项划掉并填原因（家里还有、不新鲜等）
- `👁` 看图片参考网格，`ⓘ` 看营养介绍
- `📋 导出` 生成可编辑的文字清单，方便复制发群里
- 全部买齐会有撒花动画

**分享原理**：选好的清单会编码进 URL 的 `#list=` 后面，复制链接或扫二维码给家人即可。勾选进度、挑菜勾选都存在浏览器 localStorage 里，不上传任何数据。

## 三个数据表（都在 `index.html` 里）

| 表名 | 内容 | 说明 |
|---|---|---|
| `allItemsData` | `{ n, c, tag, icon, img }` | 食材主数据：名称、分类、季节标签、兜底 emoji、图片路径 |
| `pinyinData` | `"菠菜": "bō cài"` | 带声调拼音，用于显示 |
| `nutritionData` | `"菠菜": { sum, nutri, eat, tip }` | 营养介绍四块：一句话概括、主要营养、怎么吃更好、小提示 |

数据表后面有几行自动处理：给每个食材挂上带声调的 `p`、去声调的 `py` / `pyc`、首字母 `ini`（搜索用），以及把营养信息摊平到 `sum` / `nutri` / `eat` / `tip`。

自己用「＋自选」加的食材没有拼音和营养信息，界面上会自动不显示对应内容（不会出现空白框）。

## 图片下载脚本 `download.js`

```bash
node download.js            # 下载 img/ 里还没有的图片
node download.js --force    # 忽略已有文件，全部重新下载
node download.js --apply    # 下载完顺便把 index.html 的 img 字段改成 img/xxx
```

脚本做的事情：

1. 从 `蔬菜.md` 解析出「名字 + 图片链接」，`img` 为空的自动跳过
2. 按食材名下载到 `img/`，**扩展名以文件真实内容为准**（查文件头，不信任 URL 后缀）
3. 校验下载到的是不是真图片，不是就报错，不会写坏文件
4. 已经存在且有效的图片会跳过（配合 `--force` 可强制重下）
5. `--apply` 时回写 `index.html`，写之前会核对条目数没变才落盘
6. 最后报告失败清单、仍无图片的食材、以及 `img/` 里下载了但没用上的文件

**名字对不上怎么办**：脚本里有个 `ALIAS` 表，把 `蔬菜.md` 的名字映射成 `index.html` 的名字。

```js
const ALIAS = {
  '鸡毛菜（小白菜幼苗）': '鸡毛菜',
  '尖椒': '辣椒',
  '圆椒': '青椒'
};
```

## 加一个新食材的完整流程

1. 在 `index.html` 的 `allItemsData` 里加一行，`img` 先留空：
   ```js
   { n: "秋葵", c: "瓜果", tag: "夏", icon: "🫛", img: "" },
   ```
2. 在 `蔬菜.md` 里加同名的一行，带上图片链接
3. 跑 `node download.js --apply`，图片会下到 `img/`，`index.html` 的 `img` 字段自动填好
4. 在 `index.html` 的 `pinyinData` 里补拼音，在 `nutritionData` 里补四块营养介绍
5. 刷新页面即可（无构建、无缓存）

> 名字是两边的匹配依据，**必须完全一致**（不一致就在 `ALIAS` 里做映射）。名字里带括号之类的字符也没问题。

## 当前数据规模

- 食材 **130** 种，分 10 类：叶菜 19、根茎 17、瓜果 17、菌菇 11、豆制品 8、调味 15、肉类 17、水产 12、蛋禽 5、其他 9
- 拼音 **130** 条（全覆盖）
- 营养介绍 **130** 条（全覆盖，四块内容）
- 本地图片 **77** 张；其余 53 种（主要是肉类、水产、蛋禽、调味料）`蔬菜.md` 里没有链接，卡片自动用 emoji 兜底
- `img/` 共 **79** 个文件、约 **22.8 MB**。其中 `小南瓜.webp`、`小米椒.jpg` 在 `index.html` 里没有对应食材，暂时没被引用

## 外部依赖（CDN）

页面通过 CDN 引入三个库，**离线时图片和界面仍在，但 Vue 没加载会导致页面空白**：

| 库 | 用途 | 地址 |
|---|---|---|
| Vue 3 | 整个界面的响应式渲染 | `cdn.jsdmirror.com/npm/vue@3` |
| Fuse.js 7 | 搜索框的模糊匹配 | `cdn.jsdmirror.com/npm/fuse.js@7.0.0` |
| qrcodejs | 分享弹窗里的二维码 | `cdn.jsdelivr.net/npm/qrcodejs@1.0.0` |

Fuse.js 加载失败时会自动退回子串匹配（拼音、首字母照样能搜，只是没有错字容错）。

## 已知问题 / 注意

- **首页图片体积偏大**：`img/` 里是原图，最大的 `茄子.jpg` 有 1.36 MB。卡片里用 `loading="lazy"` 按需加载，实际打开不会一次全下，但手机上首次浏览仍偏慢。如需处理，可以统一压到 600px 宽再重存。
- **沙箱内可能写不进 `img/`**：在 DSH 沙箱内运行 `download.js` 时，若 `img` 目录没有继承到工作区的写入许可，会报 `EPERM`。用放宽权限的方式运行，或直接在系统终端里跑脚本即可。脚本已经会明确报出失败原因，不会留下半截文件。
- **营养内容仅供参考**：都是通用膳食常识，不做任何疗效承诺，弹窗底部也写了「不能代替医嘱」。
- **「八角」那条有安全提示**：莽草（红毒茴）和八角外形相似但有毒，是真会吃出事的，别删。
